## 🚀 Featured Project

### [Testflow](https://github.com/karthik1710/testflow) — AI Test Automation Framework

Eliminates manual testing: reads test cases written in plain English from **TestRail**, interprets them with **GPT-4**, executes via **Playwright**, then reports pass/fail back to TestRail — zero test scripts required.

- 🤖 **AI-driven execution** — natural language → browser actions, no code
- 📊 **Vector memory (ChromaDB)** — learns from past runs, cuts AI calls 70-80%
- 🌐 **Multi-platform** — WebHMI, Siemens PLC, GitLab, TestRail integrations
- 🎯 **HIL-aware** — built for hardware-in-the-loop test execution against live rigs
- ⚡ **Real-time UI** — optional web dashboard with WebSocket live updates
- 🛠️ Stack: Python 3.12, OpenAI GPT-4, Playwright, ChromaDB, SQLite, FastAPI
